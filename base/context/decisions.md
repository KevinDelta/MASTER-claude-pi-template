# Decision Log

<!-- What goes here: Key decisions made in this project — ones that affect how the
     agent works or what it produces. Append-only. Never delete or edit past entries.

     Format: [YYYY-MM-DD] DECISION: ... | REASONING: ... | CONTEXT: ...

     Write a decision when:
     - A direction was chosen over real alternatives
     - Something was ruled out that someone might suggest again
     - A constraint was accepted that shapes future work
     - A tool, approach, or format was locked in

     Do NOT write decisions for obvious choices, defaults, or things with no real alternative.
     Every entry should be specific enough to prevent relitigating the decision.

     ESCALATION RULE — when a log entry isn't enough:
     If an entry needs more than one line of reasoning to capture, it's not a log entry
     anymore — it's an ADR. Write it as a proper ADR in the workspace's `docs/adr/`
     (per the three-criteria gate: hard to reverse + surprising + real trade-off)
     and add a one-line pointer here referencing the ADR number. Do not duplicate
     the ADR's reasoning in this file. -->
