Your work types
Each work type becomes a workspace your agent operates in. Name them as you'd describe your work to a colleague — not as system categories. 2–4 is typical.
Each entry gets its own folder under workspaces/ and a row in the routing table. Your agent will load the right context when you say what you're working on.

Generate
Your domain files are ready. Download the ZIP and run the setup script — your agent environment will be live in under a minute.
After downloading: unzip the ZIP, open the unzipped folder, then run bash setup-client.sh. The script will use the template at ~/.openclaw/templates/master-agent-template unless you set TEMPLATE_DIR=/path/to/template. Your domain will be installed at ~/.openclaw/workspaces/<slug>/ and your project repo at the path you entered in §4.
Click Regenerate to build files.
